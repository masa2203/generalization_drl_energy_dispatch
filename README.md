# Generalization with DRL in Energy System Dispatch

This repo contains the code & data of the journal paper: 

*Toward Zero-Shot Generalization of Deep Reinforcement Learning for Hybrid Energy System Dispatch*

by Manuel Sage & Khalil Al Handawi & Yaoyao Fiona Zhao (2026).

Published at the *Journal of Energy Storage* \
https://doi.org/10.1016/j.est.2026.124815
